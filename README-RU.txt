YRTORUP — ФУНКЦИОНАЛЬНОЕ ОБНОВЛЕНИЕ СООБЩЕСТВА

В архиве:
- index.html — обновлённый сайт;
- server.js — сервер SkinCash и API изображений CS2 (сохранён);
- package.json — зависимости;
- render.yaml — настройки Render.

ЧТО ТЕПЕРЬ РАБОТАЕТ
1. Ежедневная награда: повторное получение не раньше чем через 24 часа. Серия посещений повышает бонус. Состояние хранится локально и в облачном состоянии пользователя Firebase после входа.
2. Миссии: прогресс берётся из реальных действий текущего аккаунта — апгрейды, победы, число скинов, открытия кейсов. Награда выдаётся один раз за каждую миссию.
3. Достижения: автоматически открываются по фактическому прогрессу и показываются отдельной страницей и в профиле.
4. Таблица лидеров: строится по реальным публичным апгрейдам из Firestore publicUpgrades (последние 100 событий), без выдуманных ботов. Сортировка по сумме стоимости успешных апгрейдов.
5. Джекпот: общий бесплатный демо-раунд Firestore. Участие не списывает баланс/предметы; победитель выбирается только для демонстрации, награды не выдаются.
6. Профиль: сохранены Google-вход, ник, аватар, стоимость инвентаря, число предметов, апгрейды, победы и достижения.
7. Коллекции: группируют реальные предметы из инвентаря и показывают прогресс по категориям.
8. Живая лента: показывает реальные публичные апгрейды и открытия кейсов сообщества, а также локальную историю текущего пользователя.

УСТАНОВКА
1. Распакуйте архив.
2. В GitHub откройте репозиторий YRTORUP и загрузите с заменой все 4 файла в корень: index.html, server.js, package.json, render.yaml.
3. Нажмите Commit changes.
4. В Render выберите Manual Deploy → Deploy latest commit.

ВАЖНО: ДЛЯ ОБЩЕГО ДЕМО-ДЖЕКПОТА ДОБАВЬТЕ ПРАВИЛО FIRESTORE
Откройте Firebase → Firestore Database → Rules. Внутри
service cloud.firestore {
  match /databases/{database}/documents {
добавьте следующий match-блок рядом с остальными match-блоками (не внутрь другого match):

match /demoJackpots/{entryId} {
  allow read: if true;
  allow create: if request.auth != null
    && request.resource.data.uid == request.auth.uid;
  allow update: if request.auth != null
    && resource.data.uid == request.auth.uid
    && request.resource.data.uid == request.auth.uid;
  allow delete: if request.auth != null
    && resource.data.uid == request.auth.uid;
}

Затем нажмите Publish. Это разрешает читать список бесплатного раунда, но каждый вошедший пользователь может создавать и менять только свою запись. Никакие платежи, ставки или списания не используются.

Если не добавить это правило, ежедневные награды, миссии, достижения, профиль, коллекции и лента локальных/публичных апгрейдов продолжат работать в пределах существующих правил, но общий список участников джекпота не сможет синхронизироваться.

ПРИМЕЧАНИЯ
- Для облачного сохранения нужен вход Google и доступный Firestore.
- Рейтинг считает только публичные апгрейды; это не рейтинг полной стоимости инвентаря, так как текущие правила Firestore не разрешают всем читать личные документы users.
- Джекпот — исключительно визуальная демоверсия: победитель не получает предметов или денег.
- Проверен синтаксис всех встроенных JavaScript-блоков Node.js. Сам сайт на Render из этой среды не опубликован; после загрузки файлов требуется Deploy.
