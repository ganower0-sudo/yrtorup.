YRTORUP — ОБНОВЛЕНИЕ СООБЩЕСТВА И КОЛЛЕКЦИЙ

В архиве:
- index.html — обновлённый сайт;
- server.js — сервер SkinCash из предыдущей версии;
- package.json — зависимости и команда запуска;
- render.yaml — конфигурация Render.

Добавлено:
- таблица лидеров (локальный демонстрационный рейтинг с демо-участниками);
- демо-джекпот: участие бесплатное, баланс и скины не списываются, розыгрыш только симулируется;
- коллекции по типам предметов на основе инвентаря игрока;
- отдельная живая лента: открытия кейсов, апгрейды и публичные апгрейды сообщества при доступности Firestore.

Сохранено из предыдущей версии:
- ежедневные награды;
- задания и достижения;
- профиль игрока;
- кейсы, мультиоткрытие до 10 кейсов;
- SkinCash API для цен.

Установка:
1. Распакуйте архив.
2. Замените в корне GitHub-репозитория файлы index.html, server.js, package.json и render.yaml.
3. Commit changes.
4. В Render выберите Manual Deploy -> Deploy latest commit.

Важно:
Это демонстрационная версия. Джекпот не принимает ставки, не списывает баланс/предметы и не выдаёт реальные призы. Таблица лидеров содержит тестовых демо-участников; общая лента апгрейдов работает при доступной настройке Firestore.
