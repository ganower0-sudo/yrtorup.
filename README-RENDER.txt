YRTORUP — подготовка для бесплатного Render

ВАЖНО: Render обычно разворачивает проект из GitHub. Не публикуйте приватные ключи, пароли или секреты.

1. Создайте аккаунт https://github.com и войдите.
2. Нажмите + → New repository. Название: yrtorup. Выберите Private, если хотите хранить исходники приватно. Создайте репозиторий.
3. На странице репозитория выберите Add file → Upload files.
4. Загрузите СОДЕРЖИМОЕ этой папки (index.html, server.js, package.json, render.yaml и остальные файлы, если есть). Не загружайте ZIP как единственный файл. Нажмите Commit changes.
5. Откройте https://render.com и войдите/зарегистрируйтесь. Подключите GitHub.
6. Нажмите New + → Web Service и выберите репозиторий yrtorup.
7. Настройки: Runtime Node; Build Command: npm install; Start Command: npm start; Instance type: Free (если доступен для вашего аккаунта/региона).
8. Нажмите Deploy Web Service. Дождитесь статуса Live. Render выдаст публичный адрес вида https://yrtorup-xxxx.onrender.com.

Примечания:
- Сервер слушает process.env.PORT и 0.0.0.0, как требует Render.
- Бесплатный сервис может засыпать после простоя и медленно просыпаться. Бесплатные условия могут меняться; проверьте тариф перед подтверждением.
- Профиль, баланс, инвентарь и история в текущей версии хранятся в localStorage браузера. Они не синхронизируются между разными устройствами/браузерами и могут исчезнуть при очистке данных браузера.
- Кнопка вывода — внутренняя имитация, реальные предметы Steam не переводятся.
- Если цены Market.CSGO не загружаются в облаке, это может быть связано с доступностью API/ограничениями внешнего сервиса.
